# Atividade 4.2 – Sistemas Operacionais Baseados em Outros

## 🎯 Objetivo
Pesquisar e identificar cinco sistemas operacionais que foram desenvolvidos a partir de outro sistema, mostrando diferenças, componentes herdados e modificados.

---

## 🧩 Sistemas Identificados
1. **Android** → Base: Linux Kernel  
2. **Ubuntu** → Base: Debian  
3. **macOS** → Base: BSD/Darwin  
4. **ChromeOS** → Base: Gentoo Linux  
5. **Orbis OS (PlayStation 4)** → Base: FreeBSD  

---

## 📊 Tabela Comparativa

| Sistema Operacional | Base | Diferenças Principais | Componentes Herdados | Componentes Modificados |
|---------------------|------|-----------------------|----------------------|--------------------------|
| **Android** | Linux Kernel | Interface móvel, ART, serviços Google | Kernel, drivers | Sistema de arquivos, gerenciador de apps |
| **Ubuntu** | Debian | Interface amigável, atualizações rápidas | Kernel, pacotes | Repositórios, instalador |
| **macOS** | BSD/Darwin | Interface proprietária, integração Apple | Núcleo Darwin, POSIX | Sistema gráfico, drivers exclusivos |
| **ChromeOS** | Gentoo Linux | Focado em nuvem, apps web | Kernel, estrutura modular | Interface, sandbox do Chrome |
| **Orbis OS (PS4)** | FreeBSD | Otimizado para jogos, APIs proprietárias | Kernel BSD | Gerenciamento gráfico, segurança |

---

## ✔️ Conclusão
A maioria dos sistemas operacionais modernos não é criada do zero, mas adaptada de sistemas existentes, o que garante:
- **Redução de custos** de desenvolvimento.  
- **Maior estabilidade e segurança**.  
- **Reutilização de tecnologias** já testadas.  
- **Suporte e atualizações contínuas**.  

Exemplo: *“O PlayStation 4 usa um sistema operacional chamado Orbis OS, baseado no FreeBSD.”*
