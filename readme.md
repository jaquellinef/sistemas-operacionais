## 📊 Critérios de Avaliação

**Fórmula da nota final**

- Nota Final = (P1 * 0.25) + (P2 * 0.25) + ((PJ + AT) * 0.25)

**Componentes**
- **P1 — Prova 1:** 25%  
- **P2 — Prova 2:** 25%  
- **PJ — Projeto:** 25%  
- **AT — Atividades:** 25%  

**Rubrica sugerida para Projeto (PJ)**
- Funcionalidade: 40%  
- Documentação: 20%  
- Qualidade do Código: 20%  
- Apresentação: 20%
